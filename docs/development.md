# Development approach

!!! abstract ""
    Systems engineering based on stakeholder engagement to elicit user needs

## Overview

To facilitate input from stakeholders, ISO/TC 204/WG 19 hosted a series of [public workshops](workshops.md) in late 2021 with 47 stakeholders from 13 countries. ![Workshop participants by country](images/pie.png){ width="360" align=right}

The results of these workshops and follow-on meetings of WG 19 drove the development of Part 1: Vocabulary and Part 2: Operational Concept (ConOps). As these documents were finalized, efforts began to produce Part 3: System of System Requirements and Architecture (SoSR) and Part 4: System-level Requirements (SysR). The last document defines the requirements for each of the four major component systems within the METR system of systems, as defined by the architecture:

1. Regulation system
2. Distribution system
3. Consumer system
4. Discrepancy handling system

Future parts will specify:

- METR data requirements, which will define the key concepts that need to be exchanged among systems to enable METR to work
- Location referencing requirements, which will define details about how locations are used and accuracies needed for the METR system to work
- Cybersecurity requirements, which will define how METR systems and data exchanges are properly secured.

Detailed interface specifications for interoperability are likely to vary by region. Europe has begun to define elements of these exchanges within Part 11 of its DATEX-II standards. While this is already a published standard, work continues to update the standard to address all of the requirements of METR standard series.

## Stakeholders

ISO/TC 204/WG 19 continues to seek input from surface transport professionals and advocates. Perspectives of interest include:

- Regulators
- Transport users
- Support providers
- Third parties
